# Typography

## Primary typeface: Inter

Inter is the portfolio's primary sans-serif typeface and is loaded through the Google Fonts stylesheet linked in `index.html`.

| Use | Weight | Guidance |
| --- | --- | --- |
| Body copy | 400 | Comfortable line height for long-form readability |
| Navigation and labels | 500–600 | Clear, compact supporting text |
| Section headings | 700–800 | Strong hierarchy with tight letter spacing |
| Wordmark | 700 | Lowercase `benny.dev` lockup |

## Fallbacks

The CSS stack falls back through Apple system fonts and then a generic sans-serif. No font files are currently bundled in this directory.
